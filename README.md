# Portfolio · Javier Ordoñez

Sitio web personal de **Javier Ordoñez**, Backend & Cloud Software Engineer con foco en automatización con IA (Amazon Bedrock, LLMs), AWS/GCP, Golang, Node.js y TypeScript.

## Stack

- React 18 + TypeScript
- Vite 5
- lucide-react (iconos)

## Estructura

```text
src/
├── components/   # Secciones y componentes de UI
├── data/         # Contenido del portafolio (experiencia, proyectos, habilidades)
├── hooks/        # Hooks reutilizables
├── styles/       # Estilos globales
├── App.tsx
└── main.tsx
```

## Desarrollo local

```bash
npm install
npm run dev       # servidor de desarrollo
npm run build     # type-check + build de producción en dist/
npm run preview   # previsualizar el build
```

## Contenido en Markdown
